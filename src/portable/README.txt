CYBERAI MASTER - OFFLINE PC EDITION
==================================

QUICKEST START: NO INSTALLATION NEEDED
Open Cybersecurity_AI_Lab.html in a current browser such as Chrome, Edge,
Firefox, or Safari. Double-click the file, or use your browser's Open File
command. You can keep this one HTML file anywhere and send a copy to a friend.
It contains the complete lesson, the three interactive diagrams, the scenario
catalog, and the scenario generator. Internet access is not required to learn
or practice. No hosting account, API key, subscription, or Python is needed.

On Windows, Open_Lab.cmd opens the HTML in your default browser. On macOS or
Linux, opening the HTML directly is usually easiest; Open_Lab.command is an
optional shell launcher (run with: sh Open_Lab.command).

ADD THE CUSTOM WINDOWS DESKTOP ICON
Extract the complete ZIP to a folder you want to keep, then double-click
Create_Desktop_Shortcut.cmd. It creates a CyberAI Master shortcut on your
Windows Desktop using assets/cyberai-master.ico. Double-click that desktop
icon to open the lab in your default browser. No Python, installation,
administrator access, or execution-policy change is required.

Keep the extracted folder and its assets subfolder in place. If you move the
folder, run Create_Desktop_Shortcut.cmd again from the new location. The
script updates an existing shortcut only if it already points to this HTML;
otherwise it chooses an unused numbered name instead of replacing it.
The HTML by itself still works, but the desktop icon needs its ICO file.

AFTER DOWNLOADING A ZIP
Extract all files first. Open the HTML from the extracted folder. Do not leave
it inside the ZIP when you try to launch it.

WHAT IS INSIDE
- Six visual learning missions on prompts, evidence, loops, and verification.
- Three interactive diagrams that run directly in this page.
- Seeded, reusable cybersecurity practice cases from multiple scenario
  families. The generator is deterministic local code, not a live AI service.
- Prompt practice, controlled simulated tools, feedback, and study features.

SHARING
Send Cybersecurity_AI_Lab.html, or send the complete ZIP. Your friend opens
their own copy and can use the same scenario code to reproduce a practice
case. A file:// or localhost URL points to your own computer; it does not make
the lesson publicly accessible and should not be sent as a public lesson link.
The shareable online edition is a separate option if you have its HTTPS URL.

NOTES AND PROGRESS
Notes/progress are stored by your browser when its local storage is available.
Storage can vary for file:// pages and private browsing. Moving or renaming
the HTML may give it a different storage area. Use the page's export/download
controls for any work you want to keep; keep a copy of your exported file.
Research links open external websites and therefore need internet access.
The lesson itself has no external scripts, stylesheets, fonts, or API calls.

OPTIONAL LOCAL SERVER
Use only if you prefer a localhost address or your browser restricts file
storage. This option requires Python 3; normal HTML use does not.

Windows:     py Start_Local_Server.py
macOS/Linux: python3 Start_Local_Server.py

The script uses only Python's standard library. It serves this extracted
folder on 127.0.0.1, lets the operating system choose a free port, prints the
address, and opens the lab in your default browser. Keep the terminal open
while using it; press Ctrl+C to stop. It does not expose a public website.
The selected port can change on restart, which can create a separate browser
storage area. Export work you want to retain before stopping or changing ports.

ALL CASES AND TOOL ACTIONS ARE SIMULATED
Use the synthetic evidence to practice a repeatable reasoning process. No
tool in this page contacts a real account, endpoint, mail system, or service.
